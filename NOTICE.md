# Credits

This theme replaces a fork of
[pages-themes/architect](https://github.com/pages-themes/architect), a Jekyll
theme by **Jason Long** and **GitHub, Inc.**, released under
[CC0-1.0](https://creativecommons.org/publicdomain/zero/1.0/).

CC0 is a dedication to the public domain: it waives copyright and imposes no
conditions, so it requires no attribution at all. This file exists anyway,
because the theme started from theirs and saying so costs nothing.

What was actually carried over: the Jekyll theme conventions any theme must
follow — the `_layouts` / `_includes` / `_sass` / `assets` structure, the empty
front matter on `assets/css/style.scss` that makes Jekyll run it through Sass,
and the gemspec file-matching pattern. Those are the framework's conventions
rather than anyone's authorship.

Everything else here — the layouts, the includes, the stylesheet, the print
stylesheet, the drawing viewer, the project data model and the CI checks — is
new work written for this repository. `CHANGELOG.md` records it.

This theme is released under CC0-1.0 as well, so it carries the same freedom
forward.
