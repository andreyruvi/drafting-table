The three projects below are **example content shipped with the theme** to show
what the layouts do. Replace the files in `_projects/` with your own work — and
delete these.

What the theme gives you that a generic portfolio theme does not: a project page
that carries the figures a drawing set actually needs (gross floor area, site
area, plot ratio, storeys, structure, scope), a drawing list that reads like a
sheet index rather than an unlabelled image wall, and a print stylesheet that
puts all of it onto A4 or A3 instead of printing your navigation bar.
